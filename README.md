# Pinglish — 乒乓球主题渐进式英语四级训练应用

> 以乒乓球赛事体系为包装，从初中水平起步，通过碎片化闯关 + 系统化沉淀，助你稳步通过英语四六级。

## 项目背景

目标用户是一名乒乓球单招运动员，即将进入大学。英语基础约等于初中毕业水平（词汇量 1500-2000），希望在大学期间通过英语四级考试，甚至六级。

市面上所有英语学习 App（百词斩、墨墨、不背单词等）都假设用户已是高中以上水平，没有一款产品提供「从初中水平起步、以四六级为目标」的完整渐进路径。Pinglish 正是为此而生。

## 学习路径

```
初中巩固 (4周) ──→ 高中补课 (4周) ──→ 四级核心 (10周) ──→ 四级冲刺 (4周)
                                                                        ↓
                                                              六级进阶 (可选, +12周)
```

- **每日学习量**：30 分钟 / 天，每周 6 天
- **过四级总周期**：约 5.5 个月（22 周）
- **过六级总周期**：额外再加 3 个月

## 设计理念

### 为什么是 PWA？

| 对比维度 | PWA | 微信小程序 | 原生 App |
|---------|-----|-----------|---------|
| 开发成本 | 一套代码，全平台 | 审核 + 类目限制 | iOS + Android 双倍 |
| 分发 | 链接即用 | 需提交审核 | 应用商店上架 |
| 离线 | 天然支持 | 受限 | 天然支持 |
| 更新 | 即发即用 | 审核周期 | 审核周期 |
| 用户门槛 | 浏览器打开即可 | 需要微信 | 下载安装 |

**结论**：PWA 是个人项目的最优解——无需审核、一套代码、浏览器打开即用、手机可添加到桌面。

### 为什么用乒乓球主题？

目标用户是乒乓球运动员，用她熟悉的语言和荣誉体系来包装学习过程：

| 学习概念 | 乒乓球映射 |
|---------|-----------|
| 关卡 | 赛事（省赛 → 全锦赛 → 亚锦赛 → 世锦赛） |
| 正确率 | 比分（11 分制，连赢 2 分胜） |
| 连续打卡 | 连胜纪录 |
| 词汇量增长 | 世界排名提升 |
| 阶段完成 | 夺冠（省冠军 → 全国冠军 → 亚洲冠军 → 世界冠军） |

### 核心设计原则

1. **碎片化输入，系统化沉淀**：每次 10-15 分钟，适合训练间隙
2. **错了不可怕，不回来才可怕**：错题自动归档，隔天推送重练
3. **看见进步才坚持得下去**：可视化数据看板，词汇量、正确率实时可见
4. **别让她觉得在"补课"**：用赛事体系包装，是在"打比赛"不是"学英语"

## 技术栈

| 层 | 技术 | 理由 |
|-----|------|------|
| 前端框架 | Vue 3 (Composition API) | 轻量、响应式、渐进式 |
| 构建工具 | Vite 6 | 极速 HMR、开箱即用 |
| UI 方案 | 原生 CSS + CSS Variables | 无重型依赖，乒乓球主题色可配 |
| 数据存储 | IndexedDB (Dexie.js) | 本地存储题库 + 用户进度，离线可用 |
| 路由 | Vue Router 4 | SPA 页面切换 |
| 状态管理 | Pinia | 轻量、TypeScript 友好 |
| PWA | vite-plugin-pwa | Service Worker + 离线缓存 + 可安装 |
| 部署 | GitHub Pages | 免费托管、自动部署 |

## 功能模块

```
Pinglish
├── 摸底测试          —— 100 题快速定位当前水平，输出诊断报告
├── 词汇训练          —— 初中巩固 / 高中 / 四级 / 六级，四阶词库
│   ├── 选词填空
│   ├── 听音选词
│   └── 拼写闯关
├── 语法闯关          —— 按知识点拆分关卡（时态、语态、从句等）
├── 听力训练          —— 慢速 → 常速，听音选词 / 听写 / 短对话
├── 阅读训练          —— 分难度短文 + 阅读理解题
├── 模拟考场          —— 计时计分，四级/六级真题模拟
├── 错题本            —— 自动收录错题，按遗忘曲线推送复习
├── 数据看板          —— 词汇量估算、正确率趋势、薄弱项分析
└── 成就系统          —— 徽章、连胜记录、赛事冠军
```

## 竞品对比

| 竞品 | 优点 | 缺点（对目标用户） |
|------|------|-------------------|
| 百词斩 | 图文记忆强，词书全 | 起点就是四级，无渐进路径 |
| 墨墨背单词 | 遗忘曲线精准 | 界面枯燥，无趣味包装 |
| 不背单词 | 真实语境例句 | 无语法体系，无写作训练 |
| 每日英语听力 | 听力资源丰富 | 难度无法匹配初中水平 |
| 扇贝全家桶 | 听说读写全覆盖 | 各模块割裂，无统一进度 |

## Pinglish 的优劣势

**优势**：
- 量身定制，起点精准匹配初中水平用户
- 乒乓球主题沉浸式体验，降低"补课感"
- 渐进四阶段路径，不跳步、不劝退
- 全离线可用，碎片时间随时训练
- 免费、无广告、开源

**劣势**：
- 初期题库内容量有限（需人工从开源资源整理）
- 无 AI 口语陪练（需要后端支持）
- 无社交/打卡社区功能
- 数据跨设备同步需手动导入导出
